# Requirement deltas

## ADDED

### MA-SPEC-001 — Maintained current behavioral requirements

Maintain accepted behavioral requirements separately from active and archived
change records.

### MA-SPEC-002 — Structured behavioral change records

Require normalized change metadata, proposal, requirement deltas, tasks, and a
design for non-trivial behavioral changes.

### MA-SPEC-003 — Verified and safe specification archival

Apply add, modify, and remove deltas only after validation and verification,
then retain the terminal change history.

### MA-SPEC-004 — Development specifications cannot grant runtime authority

Keep specification content outside the runtime authorization and provider
execution boundary.
